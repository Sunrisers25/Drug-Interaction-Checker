# Project
**Name:** PharmaCare Pro (Drug Interaction Checker)
**Description:** A comprehensive Pharmacy Management System and Drug Interaction Checker serving as a centralized dashboard for managing pharmacy operations, verifying drug interactions, and tracking inventory and patient records.
**Tech used:** Next.js 14, React 18, Tailwind CSS, Radix UI (shadcn/ui), React Hook Form, Zod, Lucide React, Recharts
**GitHub:** [Insert GitHub Repository Link Here]
**Live link:** [https://drug-interaction-checker-pearl.vercel.app](https://drug-interaction-checker-pearl.vercel.app)

---

## 🚀 Features

- **Drug Interaction Checker:** Verify potential interactions between different medications before dispensing.
- **Medicine & Inventory Manager:** Track stock levels and receive low-stock alerts.
- **Patient Management:** Maintain safe and organized patient records.
- **Sales & Billing:** Process pharmacy transactions efficiently.
- **Analytics Dashboard:** Visualize sales and inventory statistics.
- **Camera Detection:** Advanced camera-based tracking/scanning system.
- **Secure Authentication:** Built-in login and security settings.

## 💻 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **UI Library:** React 18
- **Styling:** Tailwind CSS
- **Components:** Radix UI / shadcn/ui
- **Forms & Validation:** React Hook Form & Zod
- **Icons:** Lucide React
- **Charts:** Recharts

## 🛠️ Getting Started

1. **Clone the repository:**
   ```bash
   git clone <your-github-repo-url>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open the App:** Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Deployment
You can easily deploy this Next.js app using [Vercel](https://vercel.com/):
```bash
npm run build
npm start
```
